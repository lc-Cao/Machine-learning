## 六、模型架构

### 6.1 二分类：Sigmoid 逻辑回归

```
前向: z = X @ w.T + b  →  y = sigmoid(z) = 1 / (1 + e^{-z})
损失: CCE = -(1/N) Σ [Y·log(y) + (1-Y)·log(1-y)]
梯度: dz = (y - Y) / N,  dw = dz.T @ X,  db = Σdz
更新: w -= lr · dw,  b -= lr · db
```

- 文件：`src/model.py`
- 权重初始化：`np.random.randn(1, n_features) * 0.01`
- 偏置初始化：`0.0`
- 梯度展开式 = `y_pred - Y`（Sigmoid + 交叉熵的优雅简化）

### 6.2 多分类：Softmax 逻辑回归

```
前向: z = X @ W.T + b.T  →  y_k = e^{z_k} / Σ e^{z_j}   [W: (n_classes, n_features)]
损失: CCE = -(1/N) Σ Σ Y_ik · log(y_ik)
梯度: dW 来自 y_pred - Y（Softmax + 交叉熵的矩阵形式简化）
```

- 文件：`src/model_multiclass.py`（基线）、`src/model_multiclass_regularized.py`（带正则）、`src/model_multiclass_adam.py`（Adam）、`src/model_multiclass_earlystop.py`（早停）
- 权重初始化：`np.random.randn(n_classes, n_features) * 0.01`
- 偏置初始化：`np.zeros((n_classes, 1))`

## 七、优化技术对比

### 7.1 正则化（L1 / L2）

在 Softmax 交叉熵损失上加入正则项：

| 正则化 | 损失项 | 梯度附加项 |
|---|---|---|
| L2 | `(λ/2) · Σ w²` | `λ · w` |
| L1 | `λ · Σ |w|` | `λ · sign(w)` |

- 实验文件：`main_multiclass_regularized.py`
- L2 进一步做了 λ 网格调优：`scripts/tune_l2.py`
- L2 最佳 λ = 0.0001，L1 最佳 λ = 0.01

### 7.2 Adam 优化器

```python
m_t = β₁·m_{t-1} + (1-β₁)·dw      # 一阶矩（动量）
v_t = β₂·v_{t-1} + (1-β₂)·dw²     # 二阶矩（RMSProp 缓存）
m̂ = m_t / (1-β₁ᵗ),  v̂ = v_t / (1-β₂ᵗ)   # 偏差校正
w -= α · m̂ / (√v̂ + ε)               # 参数更新
```

- 文件：`src/model_multiclass_adam.py`
- 参数：β₁=0.9, β₂=0.999, ε=1e-8, lr=0.001

### 7.3 早停机制

- 从训练集拆分 **10% 作为验证集**
- 每轮评估验证损失，连续 `patience` 轮不提升则停止
- 停止时自动回滚到历史最佳权重
- 文件：`src/model_multiclass_earlystop.py`

## 十、结论

1. **自实现从零模型在小数据集上达到 100% 准确率，在大规模 Covtype 上略超或持平 sklearn**，验证了 NumPy 底层数学推导与梯度计算的正确性。

2. **L1 正则化（λ=0.01）是最优策略**，在三分类上准确率 77.70%，超越 sklearn 的 77.66%。L2 在此数据集上效应较弱，需要极小的 λ（0.0001）。

3. **Adam 收敛更快但最终准确率略低于 SGD+L1**，说明对于此任务，SGD 配合 L1 正则化的组合最优。

4. **早停在 150 轮内未触发**，验证损失持续下降，表明模型泛化良好且在设定的训练轮次内未过拟合。

5. 所有实验**完全可复现**——固定随机种子、统一配置管理、模块化代码结构。
